# Arion 업무 관리 Workspace

이 폴더는 PM Toolkit과 Codex·Claude Code를 함께 사용하여 Arion 프로젝트의 기획·개발 업무를 관리하는 공간입니다.

## 기본 구조

```text
Arion/
├─ CLAUDE.md / AGENTS.md        AI 작업 규칙
├─ 03_업무운영가이드.md          운영 절차
├─ 00_전체업무.kanban            전체 업무 상태
├─ 01_전체업무수행기록.md        날짜별 수행 요약
├─ 02_완료업무보관.md            정리한 완료 카드 보관
└─ 01_Arion/
   ├─ 00_기준문서/              프로젝트 전체 기준 자료 (개요, 컨셉, 아키텍처)
   ├─ 01_업무/                  개별 업무 폴더
   ├─ 02_템플릿/                업무폴더_복사용과 문서 템플릿
   └─ 99_보관함/                완료된 업무 폴더 보관
```

- `00_기준문서`: 모든 업무가 공통으로 따르는 프로젝트 전체 자료입니다. 업무를 시작하기 전에 먼저 확인하고, 변경이 필요하면 승인 후 수정합니다.
- `01_업무`: 업무마다 `NN_업무명` 폴더를 만들고, 그 안에 해당 업무의 기획·개발 내용을 누적합니다.

## 전체 업무 관리 규칙

1. 업무 진행 상태는 루트의 `00_전체업무.kanban` 한 곳에서만 관리합니다.
2. 칸반 카드명은 `업무명` 형식으로 작성합니다. (예: `회원가입 기획`, `인증 API 개발`)
3. 전체 칸반에는 실제로 추적할 수 있는 크기의 업무를 등록합니다. 큰 주제는 세부 업무로 나눕니다.
4. 새 업무의 상태를 별도로 지정하지 않으면 `백로그`에 등록합니다.
5. 칸반 컬럼은 `백로그`, `진행 중`, `완료`, `보류` 네 개만 사용합니다.
6. 업무를 수행할 때마다 해당 업무 폴더의 `04_업무수행기록.md` 한 파일에 날짜별로 수행 내용, 결과물, 이슈, 다음 할 일을 누적합니다.
7. `02_결정사항.md`, `03_회의메모.md`, `04_업무수행기록.md`는 모두 최신 날짜가 위로 오도록 작성합니다.
8. 확정된 내용은 `02_결정사항.md`, 회의 내용은 `03_회의메모.md`, 수행한 작업은 `04_업무수행기록.md`에 구분하여 기록합니다.
9. 업무가 완료되면 칸반 카드를 `완료`로 이동하고, 수행기록에 최종 결과와 산출물 위치를 남깁니다.
10. 사용자가 요청하면 완료된 업무 폴더 전체를 `01_Arion/99_보관함`으로 이동합니다.
11. PM Toolkit은 카드 목록 접기를 지원하지 않으므로, 완료 목록이 길어지면 완료 카드를 `02_완료업무보관.md`로 옮겨 메인 칸반을 정리합니다.
